## Project Deliverables

| # | Deliverable | Notes |
| :-: | :--- | :--- |
| **1** | **Project Charter, SRS & Initial DB Design** | Hoàn thành đặc tả yêu cầu (SRS), bộ quy tắc nghiệp vụ gia phả (BR), lược đồ cơ sở dữ liệu PostgreSQL + Graph Model và thiết lập môi trường Local (Docker Compose). |
| **2** | **Core Module: Auth (RBAC) & Interactive Family Tree (FE1, FE2)** | Hoàn thành xác thực người dùng (JWT), phân quyền vai trò (Admin/Trưởng họ/Thành viên), API dựng cây gia phả và thuật toán ngăn chặn chu trình vòng lặp quan hệ. |
| **3** | **Family Community, Events & Heritage Archives (FE3, FE4, FE6)** | Bàn giao bảng tin dòng họ (bài viết, bình luận, ảnh), chức năng tạo lịch giỗ/họp họ (kèm RSVP) và kho lưu trữ tài liệu lịch sử gia tộc. |
| **4** | **AI-powered Kinship Assistant & Semantic Search (FE7)** | Tích hợp Local AI Engine (chạy qua Ollama/Llama-3 cục bộ) để giải thích quan hệ xưng hô thuần Việt và tìm kiếm ngữ nghĩa thông tin người thân trong phả ký. |
| **5** | **Directory, Dashboard & System Integration Testing (FE5, FE8)** | Hoàn thiện danh bạ thành viên, biểu đồ thống kê nhân khẩu học gia tộc; thực hiện kiểm thử tự động API (Postman/Newman) và Unit Test ($\ge 70\%$ coverage). |
| **6** | **Final Local Deliverable Package, User Manual & Final Report** | Đóng gói toàn bộ mã nguồn vào `docker-compose.yml` (chạy 1 lệnh trên Localhost), hoàn thiện tài liệu hướng dẫn sử dụng, slide thuyết trình và báo cáo tổng kết. |
